## Reported Bugs

### BUG-001: WhatsApp – Chat Screen Turns Blank

**Category:** UI / Functional

**Description:**  
The chat screen turns blank or black when selecting a message for the first time after opening a chat.

**Steps to Reproduce:**
1. Open any WhatsApp chat.
2. Long-press a message.
3. Observe the chat screen.

**Actual Result:**  
Chat content becomes blank while message selection and reaction controls remain visible.

**Expected Result:**  
Chat content and the selected message should remain visible.

**Evidence:** Screen recording previously documented.

---

### BUG-002: WhatsApp – Excessive Empty Space on Status Privacy Page

**Category:** UI / Navigation

**Description:**  
The Status Privacy page displays excessive empty space when opened through Settings Search.

**Steps to Reproduce:**
1. Open WhatsApp Settings.
2. Use Settings Search.
3. Search for "Status".
4. Open Status Privacy.

**Actual Result:**  
Excessive empty space appears at the top, and scrolling does not work correctly.

**Expected Result:**  
The page should display normal spacing and support scrolling.

**Additional Observation:**  
The page works normally when accessed through Settings → Privacy → Status.

---

### BUG-003: Instagram – Share Toolbar Overlaps User List

**Category:** UI / Layout

**Device:** OnePlus 15R  
**Platform:** Android

**Description:**  
The share options toolbar overlaps the user list on the sharing screen while searching for users.

**Steps to Reproduce:**
1. Open an Instagram post.
2. Open the sharing screen.
3. Search for a user.
4. Observe the toolbar and user list.

**Actual Result:**  
The toolbar overlaps the user list and partially hides user profile details.

**Expected Result:**  
The toolbar should remain properly positioned without covering user information.

**Evidence:** Screen recording available.
